# LawyerAI — Fjolla Live Advocate

An evidence-grounded AI courtroom advocacy assistant with:
- Live avatar (Fjolla) with Rime AI voice synthesis
- Real-time case document analysis (PDF/TXT upload)
- Indian Constitution knowledge base (21 key articles)
- Speech-to-Speech dialogue
- RAG-powered legal reasoning (Ollama local LLM / cloud fallback)
- Beyond Presence video avatar integration

## Quick Start

```bash
pip install -r requirements.txt
python server.py
```

Open http://127.0.0.1:8000
