# LawyerAI — Fjolla Live Advocate

An evidence-grounded AI courtroom advocacy assistant with:
- Live avatar (Fjolla)
- Real-time case document analysis (PDF/TXT upload)
- Indian Constitution knowledge base (21 key articles)
- Speech-to-Speech dialogue
- RAG-powered legal reasoning (Cloud-resilient RAG retrieval fallback)
- Beyond Presence video avatar integration

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/HarshvardhanSR07/lawyer-ai)

## Quick Start (Local Development)

```bash
pip install -r requirements.txt
python server.py
```

Open http://127.0.0.1:8000
